## 🎯 The Problem This Solves

**Current State:** BountyWarz presents Athelgard as a rich, living mentor. Athelgard.io presents as a generic coding chat shell. The connection is invisible.

**Desired State:** Both sites clearly communicate that Athelgard is **one persistent intelligence** with four surfaces: Builder (this site), World (BountyWarz), Voice (phone), and Mobile (Android).

**This rewrite fixes:** The product bridge gap where visitors can't see how coding, game mentoring, phone guidance, and ethical bounty-hunting progression connect.

## 📝 Copy Guidelines

### Voice & Tone

**Athelgard's Voice on This Site:**
- **Clear:** No jargon without explanation
- **Confident:** Knows her domain deeply
- **Helpful:** Focused on user success
- **Ethical:** Never glib about security
- **Connected:** Always references the larger system

### What to Emphasize

✅ **DO Emphasize:**
- One persistent intelligence
- Four connected surfaces
- Ethical foundation
- Real cybersecurity learning
- BountyWarz as her home
- Builder + Player unification

❌ **DON'T Emphasize:**
- Generic "AI assistant" language
- Standalone coding tool (without BountyWarz context)
- Hacking/attacking framing
- Certification claims (use "certification-aligned")
- Unauthorized access capabilities

### Key Phrases

**Use These:**
- "living guide"
- "persistent intelligence"
- "one mind, four surfaces"
- "ethical bounty hunting"
- "responsible disclosure"
- "safe harbor principles"
- "certification-aligned"
- "Builder Mode"

**Avoid These:**
- "AI hacking companion"
- "generic coding assistant"
- "hack real targets"
- "earn real certs"
- "live exploit guide"
