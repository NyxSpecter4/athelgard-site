# Cross-Site Messaging Map

## 🎯 Purpose

This map ensures **message coherence** across BountyWarz.com and Athelgard.io so that users experience Athelgard as **one persistent intelligence**, not two separate products.

**The Core Problem:** Currently, BountyWarz presents Athelgard strongly, while Athelgard.io presents weakly. Users don't see the connection.

**The Solution:** Align messaging, terminology, visual identity, and navigation across both sites.

---

| **Athelgard.io** | Weak, generic coding chat | Full product story, clear connection to BountyWarz | Developers, Builders |
